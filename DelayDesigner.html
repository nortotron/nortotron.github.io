    Key ideas

    Key terms

    Delay time
    The gap between a sound and its copy. One beat = 60 000 ÷ BPM ms, so at 120 BPM a quarter note is 500 ms. Dotted = ×1.5, triplet = ×⅔.
    Send
    Copies some of a channel to an effect without changing the channel itself. Post-fader sends follow the channel fader (pull Source Level down and the echoes drop too). Pre-fader sends ignore it, so you can hear echoes with no dry sound.
    Return
    How loud the effect's output (the “wet” signal) is in the mix. The dry pulse and the return are summed before the Master Output.
    Filtering
    High-pass removes lows; low-pass removes highs. Because the filters are inside the loop, each repeat is filtered again, so echoes get progressively darker or thinner.
    Feedback
    Sends the filtered delay output back into the delay input. Below 100% repeats fade away; at 100% (unity) they sustain; above 100% each repeat is louder than the last, which is where overload happens.

    Core principles: how each control relates to amplitude, frequency, timbre and time

    Amplitude

    Source Level · Aux Send · Return Level · Master Output · Feedback · meters

    • Faders are gain in decibels: −6 dB roughly halves the amplitude and +6 dB doubles it. Levels in a signal chain add in dB.
    • Feedback multiplies each repeat's amplitude by the same factor. At 50%, repeat n is 0.5n (−6 dB per repeat). At 100% (unity) nothing is lost; above 100% it grows.
    • The meters and the limiter work in dBFS: 0 dBFS is the digital ceiling.

    Try: set Feedback to 50% and watch each Heard bar drop by the same amount.

    Frequency

    High-pass · Low-pass · BPM · Delay time

    • Cutoffs are in hertz (cycles per second). Frequency is logarithmic: each octave doubles it (100 → 200 → 400 Hz), which is why the knobs and plot use a log scale.
    • Tempo is also a frequency: 120 BPM = 2 beats per second (2 Hz). A delay of D ms repeats at 1000 ÷ D Hz.
    • Very short delays with feedback reinforce frequencies spaced 1000 ÷ D Hz apart (a comb filter).

    Try: set the delay to 5 ms with 90% feedback. The pulse rings at about 200 Hz.

    Timbre

    High-pass · Low-pass · Feedback · short Delay times

    • Timbre is the tone colour set by a sound's spectrum. Filtering removes parts of the spectrum; low-pass sounds darker, high-pass thinner.
    • Because the filters are in the loop, repeat n is filtered n times, so the change builds up. The dashed curve in the filter plot shows 4 passes.
    • Below roughly 30 ms, repeats fuse with the original and change its tone instead of sounding as echoes.

    Try: lower the Low-pass to 2 kHz with 60% feedback and watch the Heard colours darken.

    Time

    Delay time · BPM · note value & feel · Feedback (decay)

    • One beat = 60 000 ÷ BPM ms. Note values scale it; dotted ×1.5, triplet ×⅔.
    • Perception depends on delay time: under ~30 ms repeats fuse, ~30–100 ms is “slapback”, and longer delays are heard as distinct rhythmic echoes.
    • Feedback sets how long the pattern lasts (decay time), just as reverb time does for a room.

    Try: keep the same note value and change BPM with Tempo sync on, then off.
