Step 1: Have Audio

The Playlist Menu

Step 2: Set destination

Create and select a new empty playlist as a master edit destination, which will form the final edit

Step 3: Playlist View

Change the track to the 'Playlist' view, and observe your previously recorded playlists as folded out tracks

Step 4: The Green Button

in the image above, the last playlist is being auditioned, the green button indicates this, officially titled 'Solo Comp Lane'

Use the green listen button, play through, promoting the preferred selections to the main edit playlist
Repeat with each recording.

You can rotate a selection through the playlists with Shift + Alt + Command + Up/Down Arrow.

Step 5: Strategy

  • Start with the most recent take, which may well have been the best?
    • Work through each track linearly.
      • Delete anything unusable
      • Copy anything definite to the target playlist
    • Continue appraising the other takes, removing unwanted and filling the gaps in the main edit until satisfied.
